# Sistema de Gestión de Membresías de Gimnasio
Proyecto para administrar membresías (mensuales/anuales) de un gimnasio.

## Cómo ejecutar
Ejecuta `dart run main.dart` en la terminal.

## Investigación Corta: Clases y Objetos
- **¿Qué es una clase?** Es como un molde o una plantilla para crear cosas que comparten las mismas características.
- **¿Qué es un objeto?** Es algo creado a partir de ese molde, con sus propios datos reales.
- **¿Cuál es la diferencia entre una clase y un objeto?** La clase es el plano (abstracto) y el objeto es la casa ya construida (real).
- **¿Qué es un atributo?** Son las variables o características que tiene una clase (ej. nombre, edad).
- **¿Qué es un método?** Son las funciones que están adentro de una clase, que le dicen qué acciones puede hacer.
- **¿Para qué sirve un constructor?** Es una función especial que se ejecuta justo cuando creas el objeto, y sirve para darle sus valores iniciales.
